# 바이낸스 선물 급등 예측 시스템

**머신러닝 기반 암호화폐 급등 패턴 학습 및 실시간 예측 시스템**

바이낸스 선물 시장에서 급등하는 코인들의 **급등 직전 공통 패턴**을 머신러닝으로 학습하고, 학습된 패턴을 바탕으로 **현재 급등 가능성이 높은 코인을 실시간으로 탐지**하는 시스템입니다.

## 🎯 핵심 개념

### 기존 문제점
- 바이낸스 앱: "이미 급등한" 코인만 보여줌 → 타이밍 놓침
- 현재 실시간 모니터링: 의미 없음 (바이낸스가 더 빠름)

### 우리의 접근 방식
1. **과거 급등 코인들의 "급등 직전" 패턴 학습** (머신러닝)
2. **학습된 패턴으로 "지금" 급등할 코인 예측**
3. **실시간으로 바이낸스 전체 선물 코인 스캔** → 급등 직전 패턴 감지

## ⚡ 주요 기능

### 1. 급등 패턴 학습 (머신러닝)
- 과거 3-6개월간 급등한 코인들의 데이터 수집
- 급등 "직전" 특징 추출:
  - 가격 및 거래량 패턴
  - 기술적 지표 (RSI, MACD, 볼린저밴드, 등)
  - 펀딩비율, 미결제약정, 롱/숏 비율
  - 소셜 미디어 활동 (LunarCrush API)
  - 온체인 데이터 (선택)
- XGBoost/LightGBM 모델로 급등 패턴 학습

### 2. 실시간 급등 예측
- 바이낸스 전체 USDT 선물 코인 스캔
- 학습된 모델로 각 코인의 급등 확률 계산
- 높은 확률 코인 실시간 알림

### 3. 백테스팅 시스템
- 과거 데이터로 예측 정확도 검증
- 실제 수익률 시뮬레이션
- Precision, Recall, F1-Score 추적

### 4. 성능 추적
- 실시간 예측 정확도 모니터링
- False Positive/Negative 분석
- 일별 성능 리포트

## 🚀 설치 및 사용

```bash
python run.py
```

## 🔧 설정 커스터마이징

`config/config.py` 에서 다양한 설정 변경 가능:

```python

# 데이터 수집 기간
SCAN_DAYS = 180  # 6개월

# 예측 임계값
PREDICTION_MIN_PROBABILITY = 0.7  # 70% 이상만 알림

# 스캔 간격
PREDICTION_SCAN_INTERVAL = 300  # 5분

# 백테스팅 설정
BACKTEST_INITIAL_BALANCE = 10000  # 초기 자본
BACKTEST_POSITION_SIZE = 0.1  # 포지션 크기 10%
```

## ⚠️ 주의사항

### 투자 경고
- 이 도구는 **과거 데이터 분석**을 기반으로 하며, **미래 수익을 보장하지 않습니다**
- 암호화폐 투자는 **높은 리스크**를 수반합니다
- 반드시 **본인의 투자 원칙**과 **리스크 관리 전략**을 수립하세요
- **투자 손실의 책임은 투자자 본인**에게 있습니다

### 기술적 한계
- **과적합(Overfitting)**: 과거 패턴이 미래에도 유효하다는 보장 없음
- **거짓 신호(False Positives)**: 급등 예측이 틀릴 수 있음
- **시장 변화**: 시장 구조 변화 시 모델 재학습 필요
- **데이터 품질**: API 오류, 네트워크 문제 등으로 데이터 누락 가능

### 사용 권장사항
1. **충분한 데이터 수집** (최소 3개월, 권장 6개월)
2. **정기적인 모델 재학습** (월 1회 이상)
3. **백테스팅으로 성능 검증** 후 실사용
4. **보수적인 임계값** 설정 (70% 이상 권장)
5. **다른 분석 도구와 병행** 사용
