# 바이낸스 선물 급등 코인 패턴 분석 도구

바이낸스 선물 거래소에서 10% 이상 급등하는 코인들의 **급등 전 공통 패턴**을 탐지하고 분석하는 도구입니다.

## 주요 기능

### 1. 급등 코인 스캔
- 24시간 기준 10% 이상 급등한 코인 실시간 스캔
- 최근 7일간 급등 이벤트 히스토리 분석

### 2. 다차원 데이터 수집
바이낸스 API를 통해 다음 데이터를 수집합니다:
- **가격 데이터**: OHLCV (시가, 고가, 저가, 종가, 거래량)
- **거래량**: 급등 전후 거래량 변화 패턴
- **펀딩비율**: 선물 시장 심리 지표
- **미결제약정 (Open Interest)**: 시장 참여도
- **롱/숏 비율**: 투자자 포지션 분석
- **시가총액**: CoinGecko API 연동 (선택)

### 3. 패턴 분석 알고리즘
급등 전 데이터를 분석하여 다음 패턴을 탐지합니다:
- ✅ 거래량 급증 (평균 대비 2배 이상)
- ✅ 가격 저항선 돌파
- ✅ 연속 상승 캔들
- ✅ 펀딩비율 변화 추세
- ✅ 롱/숏 비율 불균형
- ✅ 변동성 증가

### 4. 공통 패턴 탐색
여러 급등 이벤트의 공통 특징을 통계적으로 분석하여 점수화합니다.

### 5. 시각화 및 리포트
- 급등 전후 가격/거래량 차트
- 펀딩비율 변화 차트
- 공통 패턴 레이더 차트
- 텍스트 분석 리포트

## 설치 방법

### 1. 필요한 라이브러리 설치
```bash
pip install -r requirements.txt
```

### 2. 환경변수 설정 (선택사항)
```bash
cp .env.example .env
# .env 파일을 열어서 바이낸스 API 키 입력 (선택사항)
```

**참고**: 바이낸스 API 키는 선택사항입니다. 공개 데이터(가격, 거래량, 펀딩비율 등)는 API 키 없이도 조회 가능합니다.

## 사용 방법

### 메인 프로그램 실행
```bash
python run.py
```

### 메뉴 옵션

1. **현재 급등 코인 스캔**
   - 현재 24시간 기준 10% 이상 급등한 코인 리스트 표시

2. **과거 급등 이벤트 패턴 분석 (7일)**
   - 최근 7일간 급등 이벤트를 스캔
   - 각 이벤트의 급등 전 패턴 분석
   - 공통 패턴 통계 생성
   - 차트 및 리포트 자동 생성

3. **실시간 모니터링**
   - 1분마다 급등 코인을 체크
   - 새로운 급등 발견 시 알림
   - 거래량 급증 패턴 즉시 감지

4. **저장된 패턴 분석 결과 보기**
   - 데이터베이스에 저장된 과거 분석 결과 조회
   - 패턴 점수 기준 상위 10개 표시

## 설정 커스터마이징

`config/config.py` 파일에서 다음 설정을 변경할 수 있습니다:

```python
SURGE_THRESHOLD = 10.0              # 급등 기준 (%)
SCAN_DAYS = 7                       # 스캔할 기간 (일)
LOOKBACK_HOURS_BEFORE_SURGE = 72   # 급등 전 분석할 시간 (시간)
VOLUME_SURGE_MULTIPLIER = 2.0       # 거래량 급증 기준 (배수)
```

### 패턴 점수
각 급등 이벤트는 0-100점으로 점수화됩니다:
- **거래량 급증**: 최대 30점
- **저항선 돌파**: 최대 20점
- **연속 상승 캔들**: 최대 15점
- **가격 추세**: 최대 15점
- **펀딩비율 변화**: 최대 10점
- **롱/숏 비율**: 최대 10점

## 활용 방법

1. **패턴 학습**: 과거 급등 이벤트를 분석하여 공통 패턴 파악
2. **실시간 모니터링**: 학습된 패턴과 유사한 코인 실시간 감지
3. **매매 전략 수립**: 패턴 점수가 높은 코인을 진입 후보로 선정
4. **리스크 관리**: 거래량, 변동성 등을 고려한 포지션 사이징
